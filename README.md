# Care 4 Cancer (C4C) Custom 60% Keyboard

### What I Built
A custom, compact 60% mechanical typing keyboard housed in structural carbon fiber plates, using plate-mounted tactile switches.

### Why I Built It
As a co-founder of Care 4 Cancer (C4C), I engineered this keyboard as a branded tool to celebrate our community organization. It features our signature brand color palette: Deep Neon Blue (#38b6ff) and Bright Yellow (#ffc000), paired with clean, MacBook-style centered text alignment and a dedicated "C4C" key shortcut.

### What I Learned
I learned how to construct a digital layout blueprint using hex code matrices, map custom key alignments, and structure project repositories to meet open-source engineering standards.
