# Care 4 Cancer (C4C) Custom 60% Keyboard

### Project Overview
A custom 60% hand-wired mechanical keyboard featuring a C4C-branded Deep Neon Blue (#38b6ff) and Bright Yellow (#ffc000) theme. The build utilizes 61 Gateron Linear switches, a hand-wired matrix with 1N4148 diodes, and a Raspberry Pi Pico (KMK firmware) in a custom Carbon Fiber frame.

### Key Learnings & Features
-   **Method:** Hand-wired matrix configuration.
-   **Design:** MacBook-style centered text with a custom "C4C" key.
-   **Skills:** Mapping custom key alignments and project repository management.

### Bill of Materials (BOM)
*   **Switches:** 61x Gateron Linear (3-Pin)
*   **Keycaps:** Custom Blue & Yellow (OEM Profile)
*   **Plate/Case:** Carbon Fiber 60% (Top/Bottom)
*   **Controller:** Raspberry Pi Pico (RP2040)
*   **Diodes:** 61x 1N4148 Axial
*   **Stabilizers:** Cherry MX Plate Mount (60%)
